## Critical Gaps (Must Fix)

### 1. Stale closure in event dialog reminder save (REMN-01, REMN-04)

**File:** `components/calendar/event-dialog.tsx:265`
**Issue:** `handleSubmit` useCallback is missing `reminderRows` and `reminderLoadFailed` from its dependency array. Reminder edits made after dialog open are captured at first render, not at submit time.
**Fix:** Add `reminderRows` and `reminderLoadFailed` to the dependency array.

### 2. Workouts not at start time (AGGR-04)

**File:** `lib/calendar/feed-aggregation.ts`
**Issue:** `normalizeWorkouts` hard-codes `startTime: null` and `allDay: true` — time not extracted from `started_at`.
**Fix:** Extract `w.started_at.split('T')[1]?.slice(0, 5)` for startTime.

### 3. Layer defaults only enable events (AGGR-06)

**File:** `components/calendar/calendar-page-content.tsx:83`
**Issue:** `enabledLayers` initialized as `new Set(["events"])` — other domains OFF by default.
**Fix:** Change to `new Set(["events", "tasks", "habits", "bills", "workouts"])`.

### 4. Timezone never persists (INFR-07)

**File:** `app/api/profile/route.ts` + `lib/hooks/use-timezone-detection.ts`
**Issue:** Two breaks: (a) `useTimezoneDetection` hook never called, (b) PATCH handler ignores timezone field.
**Fix:** (a) Add timezone guard to PATCH handler, (b) Wire hook in root layout or provider.
