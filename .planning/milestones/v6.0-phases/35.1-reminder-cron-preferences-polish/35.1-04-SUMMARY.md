## Decisions Made
- Used mobileSidebar ReactNode render prop instead of duplicating sidebar logic in header -- cleaner separation, single source of truth for sidebar content
- useSwipe threshold set at 50px with 1.5x horizontal dominance ratio -- prevents false triggers during vertical time grid scrolling
- FAB uses same handleNewEvent handler as existing "+ New Event" button for consistency
