```sql
CREATE TABLE calendar_events (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID NOT NULL REFERENCES profiles(id) ON DELETE CASCADE,
  title TEXT NOT NULL,
  description TEXT,
  start_date DATE NOT NULL,
  start_time TIME,
  end_date DATE NOT NULL,
  end_time TIME,
  location TEXT,
  color TEXT,
  category_id UUID REFERENCES categories(id) ON DELETE SET NULL,
  is_recurring BOOLEAN NOT NULL DEFAULT false,
  recurrence_rule JSONB,
  end_type TEXT CHECK (end_type IN ('never', 'after_count', 'on_date')),
  end_date_recurrence DATE,
  end_count INTEGER,
  recurring_event_id UUID REFERENCES calendar_events(id) ON DELETE CASCADE,
  original_date DATE,
  is_exception BOOLEAN NOT NULL DEFAULT false,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW(),
  CONSTRAINT chk_allday_consistency CHECK (start_time IS NOT NULL OR (start_time IS NULL AND end_time IS NULL))
);
```
With indexes:
- `idx_calendar_events_user_date ON calendar_events(user_id, start_date)`
- `idx_calendar_events_user_range ON calendar_events(user_id, start_date, end_date)`
- `idx_calendar_events_recurring ON calendar_events(recurring_event_id) WHERE is_exception = true`
- `idx_calendar_events_is_recurring ON calendar_events(user_id) WHERE is_recurring = true`

RLS: Enable + 4 standard policies (SELECT/INSERT/UPDATE/DELETE) using `auth.uid() = user_id`.

**3. CREATE TABLE reminders:**
```sql
CREATE TABLE reminders (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID NOT NULL REFERENCES profiles(id) ON DELETE CASCADE,
  source_type TEXT NOT NULL CHECK (source_type IN ('calendar_event', 'task', 'habit', 'bill')),
  source_id UUID NOT NULL,
  reminder_type TEXT NOT NULL CHECK (reminder_type IN ('relative', 'absolute')),
  relative_minutes INTEGER,
  absolute_time TIMESTAMPTZ,
  channels TEXT[] NOT NULL DEFAULT '{push}',
  status TEXT NOT NULL CHECK (status IN ('pending', 'sent', 'failed', 'snoozed')) DEFAULT 'pending',
  fire_at TIMESTAMPTZ NOT NULL,
  sent_at TIMESTAMPTZ,
  created_at TIMESTAMPTZ DEFAULT NOW()
);
```
With indexes:
- `idx_reminders_fire_at ON reminders(fire_at) WHERE status = 'pending'` (critical cron query)
- `idx_reminders_user_source ON reminders(user_id, source_type, source_id)`
- `idx_reminders_user ON reminders(user_id)`

RLS: Enable + 4 standard policies.
