<feature>
  <name>Exception-Aware Recurrence Expansion</name>
  <files>lib/calendar/recurrence.ts, tests/lib/calendar/recurrence.test.ts</files>
  <behavior>
    **ExpandedCalendarEvent type:**
    - Extends CalendarEvent with `is_virtual: boolean` property (D-05)

    **expandEventsForRange(events: CalendarEvent[], startDate: string, endDate: string): ExpandedCalendarEvent[]**

    Case 1: Standalone events pass through unchanged with is_virtual=false
      - Input: [{ id: 'e1', is_recurring: false, is_exception: false, start_date: '2026-04-01', end_date: '2026-04-01' }]
      - Range: '2026-04-01' to '2026-04-30'
      - Output: [{ ...event, is_virtual: false }]

    Case 2: Recurring daily event expands to virtual occurrences
      - Input: [{ id: 'r1', is_recurring: true, start_date: '2026-04-01', end_date: '2026-04-01', recurrence_rule: { frequency: 'daily', interval: 1 }, end_type: 'never' }]
      - Range: '2026-04-01' to '2026-04-03'
      - Output: 3 virtual events with is_virtual=true, IDs 'r1_2026-04-01', 'r1_2026-04-02', 'r1_2026-04-03', recurring_event_id='r1'

    Case 3: end_type 'on_date' limits expansion
      - Recurring daily from '2026-04-01', end_date_recurrence='2026-04-05'
      - Range: '2026-04-01' to '2026-04-10'
      - Output: Only 5 virtual occurrences (04-01 through 04-05)

    Case 4: end_type 'after_count' limits to N total occurrences
      - Recurring daily from '2026-04-01', end_count=3
      - Range: '2026-04-01' to '2026-04-10'
      - Output: Only 3 virtual occurrences (04-01, 04-02, 04-03)

    Case 5: after_count with range starting after some occurrences
      - Recurring daily from '2026-04-01', end_count=5
      - Range: '2026-04-03' to '2026-04-10'
      - Output: 3 virtual occurrences (04-03, 04-04, 04-05) — first 2 are before range

    Case 6: Exception suppresses virtual occurrence and replaces it
      - Recurring daily parent 'r1' from '2026-04-01'
      - Exception: { recurring_event_id: 'r1', original_date: '2026-04-02', is_exception: true, title: 'Modified', start_date: '2026-04-02' }
      - Range: '2026-04-01' to '2026-04-03'
      - Output: virtual 04-01, exception record (not virtual) for 04-02, virtual 04-03

    Case 7: Exception moved to different date
      - Exception with original_date='2026-04-02' but start_date='2026-04-05'
      - The virtual occurrence for 04-02 is suppressed; the exception appears at its own start_date
      - If exception's start_date is outside the query range, it still suppresses 04-02

    Case 8: Multi-day recurring event preserves duration
      - Parent: start_date='2026-04-01', end_date='2026-04-03' (3-day event), recurring weekly
      - Virtual occurrence on 04-08: start_date='2026-04-08', end_date='2026-04-10'

    Case 9: Empty input returns empty output
    Case 10: Recurring parent without recurrence_rule (edge case) is skipped gracefully
  </behavior>
  <implementation>
    1. Create `lib/calendar/recurrence.ts` with:
       - `ExpandedCalendarEvent` type: `CalendarEvent & { is_virtual: boolean }`
       - `expandEventsForRange(events, startDate, endDate)` function per algorithm in RESEARCH.md

    2. Algorithm (per D-03, D-04, D-05, D-06):
       a. Separate events into standalone, recurring parents, and exceptions
       b. Index exceptions by `recurring_event_id` → Map of `original_date` → exception
       c. Add standalone events with `is_virtual: false`
       d. For each recurring parent:
          - Guard: skip if `recurrence_rule` is null
          - Call `getOccurrencesInRange(parent.recurrence_rule, parent.start_date, startDate, endDate)`
          - Apply end_type limits:
            - 'on_date': filter dates <= end_date_recurrence
            - 'after_count': get all dates from parent.start_date to endDate, take first end_count, intersect with range
          - Calculate duration_days = daysBetween(parent.start_date, parent.end_date)
          - For each occurrence date:
            - If exception exists for this date → add exception with is_virtual=false (do NOT add to result again later)
            - Else → create virtual: spread parent, override id=`${parent.id}_${date}`, start_date=date, end_date=date+duration_days, is_virtual=true, recurring_event_id=parent.id, original_date=date
       e. Add any exceptions whose original_date is NOT in the expanded dates set but whose start_date falls in range (moved exceptions)
       f. Return result sorted by start_date, start_time

    3. Helper: `daysBetween(a: string, b: string): number` — calculates day difference between two YYYY-MM-DD strings
  </implementation>
</feature>
