<objective>
Build the unified calendar feed API and integrate cross-domain items into the existing calendar UI.

Purpose: Users see tasks, habits, bills, and workouts on their calendar alongside events.
Output: Feed API endpoint, aggregation logic, sidebar layer toggles, domain-colored items on calendar views.
</objective>

## Tasks

### Task 1: CalendarFeedItem types and domain color mapping
Create `lib/calendar/feed-types.ts` with the CalendarFeedItem type, FeedSource union, and DOMAIN_COLORS constant.

### Task 2: Pure aggregation functions
Create `lib/calendar/feed-aggregation.ts` with functions to convert each domain's data into CalendarFeedItem arrays.

### Task 3: Feed API endpoint
Create `app/api/calendar/feed/route.ts` — GET handler that queries all domains in parallel and returns merged feed.

### Task 4: Unit tests for aggregation functions
Create `tests/lib/calendar/feed-aggregation.test.ts` testing all four domain converters.

### Task 5: API route tests
Create `tests/app/api/calendar/feed/route.test.ts` testing the feed endpoint.

### Task 6: Integrate feed into calendar page
Update CalendarPageContent to fetch from feed API alongside events, merge items, and pass to views. Update sidebar to enable all layer toggles and propagate enabled layers.

### Task 7: i18n strings for feed items
Add feed-related i18n keys to all 3 locale files.
