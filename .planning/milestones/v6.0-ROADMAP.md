- Vercel Cron → GitHub Actions cron (Hobby plan limitation)
- HMAC-based timing-safe auth for cron endpoint
- Extended EventChip/EventBlock with _domain field instead of separate CalendarItemChip/Block
- Lazy Resend client init to prevent build failure without API key
- reminderCreateSchema extended with .and() for event_start_time

- Stale closure in event dialog reminder save (reminderRows missing from useCallback deps)
- Timezone not persisting (PATCH handler missing field + hook not wired)
- Silent data destruction when reminder fetch fails in edit mode
- Timing-unsafe CRON_SECRET comparison
