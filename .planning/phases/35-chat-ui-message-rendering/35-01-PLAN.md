    **ChatInput** (`components/chat/chat-input.tsx`):
    - "use client" directive
    - Import: Button from '@/components/ui/button', cn from '@/lib/utils', useRef/useState/useCallback from 'react', Send/Square from 'lucide-react'
    - Props interface `ChatInputProps`:
      - `onSend: (text: string) => void` — called with trimmed text
      - `onStop: () => void` — called when Escape pressed during streaming
      - `isStreaming: boolean` — controls button state and Escape behavior
      - `disabled?: boolean` — optional external disable
    - Internal state: `const [input, setInput] = useState('')`
    - `textareaRef = useRef<HTMLTextAreaElement>(null)`
    - Per D-10: `adjustHeight()` function — sets `textarea.style.height = 'auto'` then `Math.min(textarea.scrollHeight, 150) + 'px'`. Called in `useEffect` on input change.
    - Per D-12: `handleKeyDown` function:
      - `if (e.key === 'Enter' && !e.shiftKey && !e.nativeEvent.isComposing)` — `e.preventDefault()`, call `handleSend()` if `input.trim() && !isStreaming`
      - `if (e.key === 'Escape' && isStreaming)` — `e.preventDefault()`, call `onStop()`
    - `handleSend()`: call `onSend(input.trim())`, `setInput('')`, reset textarea height
    - Per D-11: Layout: `div.flex items-end gap-2 p-4 border-t border-border bg-background`
      - Textarea: `flex-1 resize-none min-h-[40px] max-h-[150px] overflow-y-auto rounded-xl border border-input bg-background px-4 py-2.5 text-sm`, placeholder: "Message..."
      - When isStreaming: show stop button (Square icon, variant="ghost", size="icon", onClick=onStop) per D-08
      - When not streaming: show send button (Send icon, variant="default", size="icon", onClick=handleSend, disabled when `!input.trim()` per D-11)
    - Export named `ChatInput`
