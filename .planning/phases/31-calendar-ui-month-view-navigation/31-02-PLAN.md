1. Create `lib/calendar/date-utils.ts` with these exported utilities:

   **`getMonthGridDates(year: number, month: number, weekStartDay: number): Date[]`**
   - Returns array of 35 or 42 Date objects representing the full month grid
   - Starts from the weekStartDay of the week containing the 1st of the month
   - Ends when 5 or 6 complete weeks are filled
   - Example: April 2026, weekStartDay=0 (Sun) -> starts March 29, ends May 3 (35 days)

   **`getDateString(date: Date): string`**
   - Returns YYYY-MM-DD string for a Date object (using local date, NOT UTC)
   - Use `date.getFullYear()`, `date.getMonth()`, `date.getDate()` — never toISOString()

   **`groupEventsByDate(events: ExpandedCalendarEvent[]): Map<string, ExpandedCalendarEvent[]>`**
   - Groups events by `start_date` into a Map
   - For multi-day events (start_date !== end_date), add the event to EACH date it spans
   - Sort events within each day: all-day (start_time === null) first, then by start_time ascending

   **`getMonthDateRange(year: number, month: number, weekStartDay: number): { startDate: string; endDate: string }`**
   - Uses getMonthGridDates to determine the padded date range for the API call
   - Returns first and last date as YYYY-MM-DD strings
