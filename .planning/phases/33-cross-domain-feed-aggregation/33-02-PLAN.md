<action>
Create `app/api/calendar/feed/route.ts` with a `GET` handler:

1. **Auth & validation** (same pattern as calendar-events route):
   - `const supabase = await createClient()`
   - Get user, return 401 if unauthenticated
   - Validate `start_date` and `end_date` query params (YYYY-MM-DD format, both required)

2. **Parallel data fetching** with `Promise.all`:
   ```ts
   const calendarEventsDB = new CalendarEventsDB(supabase);
   const tasksDB = new TasksDB(supabase);
   const habitsDB = new HabitsDB(supabase);
   const habitLogsDB = new HabitLogsDB(supabase);
   const householdsDB = new HouseholdsDB(supabase);
   const workoutsDB = new WorkoutsDB(supabase);

   // Resolve household first (needed for bills)
   let householdId: string | null = null;
   try {
     householdId = await householdsDB.resolveHousehold(user.id);
   } catch {
     // No household = no bills, that's OK
   }

   const [rawEvents, tasks, activeHabits, habitLogs, bills, workouts] = await Promise.all([
     calendarEventsDB.getUserEvents(user.id, startDate, endDate),
     tasksDB.getTasksInDateRange(user.id, startDate, endDate),
     habitsDB.getActiveHabits(user.id),
     habitLogsDB.getUserLogsByDateRange(user.id, startDate, endDate),
     householdId ? new RecurringBillsDB(supabase).getByHousehold(householdId) : Promise.resolve([]),
     workoutsDB.getWorkoutsByDateRange(user.id, startDate, endDate),
   ]);
   ```

3. **Normalize & merge**:
   ```ts
   const events = expandEventsForRange(rawEvents, startDate, endDate);
   const items: CalendarItem[] = [
     ...normalizeEvents(events),
     ...normalizeTasks(tasks),
     ...normalizeHabits(activeHabits, habitLogs, startDate, endDate),
     ...normalizeBills(bills, startDate, endDate),
     ...normalizeWorkouts(workouts),
   ];
   ```

4. **Sort** by `start_date` then `start_time` (nulls/all-day first within each date):
   ```ts
   items.sort((a, b) => {
     const dateCmp = a.start_date.localeCompare(b.start_date);
     if (dateCmp !== 0) return dateCmp;
     if (a.start_time === null && b.start_time === null) return 0;
     if (a.start_time === null) return -1;
     if (b.start_time === null) return 1;
     return a.start_time.localeCompare(b.start_time);
   });
   ```

5. **Return**: `NextResponse.json({ items })`

6. **Error handling**: wrap in try/catch, log error, return 500.
