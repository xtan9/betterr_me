Create `components/calendar/calendar-item-chip.tsx`:

Props:
```ts
interface CalendarItemChipProps {
  item: CalendarItem;
  onClick?: () => void;
  onAction?: () => void;  // For inline action (task/habit/bill toggles)
}
```

Rendering logic by source:
- **event**: Same as current EventChip — border-l color from `item.color` or `--calendar-event`, show time + title. Use custom color if `item.meta.is_virtual !== undefined` and `item.color !== DOMAIN_COLORS.event`.
- **task**: Circle icon (lucide `Circle` or `CheckCircle2` if completed) + title. Blue domain color (`--calendar-task`). Completed tasks show strikethrough.
- **habit**: Square icon (lucide `Square` or `CheckSquare` if logged) + title. Amber domain color (`--calendar-habit`).
- **bill**: DollarSign icon + title + amount display. Red domain color (`--calendar-bill`). Paid bills show muted style.
- **workout**: Dumbbell icon + title. Purple domain color (`--calendar-workout`).

All variants use `hsl(var(--${item.color}))` for the border-left and `hsl(var(--${item.color}-muted))` for background (same CSS variable pattern as events, which already have `--calendar-event-muted`). For non-event domains, define CSS variable references with fallbacks.

The `onAction` handler is called when clicking the action icon (checkbox/dismiss) — stopping propagation so it doesn't trigger the chip's `onClick`. If no `onAction` provided, the icon is not interactive.

Mark component as `"use client"`.
</action>

2. Create a new function `groupItemsByDate` that works with `CalendarItem[]`:
   ```ts
   export function groupItemsByDate(items: CalendarItem[]): Map<string, CalendarItem[]> {
     const map = new Map<string, CalendarItem[]>();
     for (const item of items) {
       const start = item.start_date;
       const end = item.end_date;
       if (start === end) {
         const existing = map.get(start) || [];
         existing.push(item);
         map.set(start, existing);
       } else {
         // Multi-day item: add to each date it spans
         // (same logic as groupEventsByDate)
       }
     }
     // Sort within each day: all-day first, then by start_time
     for (const [, dayItems] of map) {
       dayItems.sort((a, b) => {
         if (a.start_time === null && b.start_time === null) return 0;
         if (a.start_time === null) return -1;
         if (b.start_time === null) return 1;
         return a.start_time.localeCompare(b.start_time);
       });
     }
     return map;
   }
   ```

3. Keep the old `groupEventsByDate` function for backward compatibility (it may be used in tests or other places), but it can be deprecated with a comment.
